# Changelog

## Stage 3 — Queue, Fairness, Simulation
- Додано логіку справедливого вибору курʼєра (з урахуванням навантаження)
- Реалізовано чергу замовлень (`queue`) з автоматичною переобробкою
- Додано симуляцію виконання у часі (таймери)
- Розширено UI:
  - відображення черги, ресторанів та активних доставок
  - автоматична генерація ID
  - покращена панель логів
- Додано стартові дані (курʼєри, замовлення, ресторани)
